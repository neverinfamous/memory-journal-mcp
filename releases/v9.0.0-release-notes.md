# Memory Journal MCP v9.0.0

## Highlights

- **Multi-Tenant Workspace Isolation**: Partition multiple project journals safely inside a single SQLite database. Auto-resolution maps your working directory to the active workspace and project automatically.
- **Native CLI Subcommand Architecture**: Execute journal operations directly via typed `exec` and `admin` subcommands. Bypass MCP serialization overhead for large payloads with recursive JSON help schemas.
- **Git History Mining & Velocity Briefings**: Query commits, releases, and patterns with five new Git mining tools. Session briefings now surface semantic velocity metrics and confidence scores natively.
- **Full-Stack Observability**: Monitor server health with Prometheus `/metrics`, Datadog, Grafana, and Loki integration. Track per-tool p50/p95/p99 latency percentiles and persistent execution telemetry.
- **Hardened Code Mode & Autonomous Healing**: Execute multi-step scripts faster using a pre-warmed sandbox worker pool. Multi-layer anti-hallucination guardrails automatically normalize parameters, aliases, and schema mismatches.
- **SEP-2640 Bundled Agent Skill**: Serve the sanitized `memory-journal-mcp` skill directly through MCP protocol resources. Equip connected AI agents with foundational rules and zero manual setup.

## Added

- **workspace**: Implement `workspace_id` multi-tenancy isolation, CWD auto-discovery, and `targetWorkspaceId` entry migration.
- **cli**: Add subcommand architecture (`entry`, `exec`, `admin`, `project`), recursive JSON help, and `ts-pattern` Zod bridge.
- **cli**: Support single-file YAML frontmatter, `--auto-context-file`, `--rel-file`, and `stdin` payloads for frictionless entry creation.
- **git**: Add `get_commit_history`, `search_commits`, `get_release_info`, `get_unreleased_commits`, and `analyze_commit_patterns` mining tools.
- **observability**: Add Prometheus `/metrics` exporter, p50/p95/p99 latency tracking, and Datadog/Grafana/Loki infrastructure stack.
- **skills**: Bundle the `memory-journal-mcp` skill and serve it natively via SEP-2640 protocol resources.
- **core**: Add `batch_create_entries` and `batch_delete_entries` tools for core and team databases.
- **project**: Add `register_project`, `update_project`, `delete_project`, `list_projects`, and `get_project` registry CRUD tools.
- **trust**: Introduce entry `trustScore`, `impactScore`, document anchors, and `memory://staleness` tracking resources.
- **team**: Add `cross_team_search` across dynamic team databases, author alias management, and retro-consolidation tools.
- **lifecycle**: Implement graduated 3-stage data lifecycle with `mj_run_auto_prune`, `--dry-run`, and `--exclude-tags` controls.
- **subscriptions**: Add real-time `resources/subscribe` support across core, team, and flag resources.
- **search**: Implement keyset cursor pagination, fuzzy search fallback, and swappable vector embedding models.
- **scheduler**: Add scheduled report delivery with webhook notifications and persistent metrics storage.

## Changed

- **briefing**: Shift session briefing to semantic `lib-git-history` payloads with dynamic velocity summaries and path compression.
- **codemode**: Upgrade sandbox to a pre-warmed worker pool with `createJournalApi` bindings and graceful restart handling.
- **scheduler**: Tie `validation_status` directly into entry importance scoring and automated pruning intervals.
- **prompts**: Redesign `commit`, `optimize-journal`, and adversarial audit prompts with semantic validation tiers and subagent partitioning.
- **database**: Add composite and partial SQLite indexes alongside RBAC caching to accelerate multi-project queries.
- **testing**: Expand unit test coverage above 81% with 1,782 unit tests and 448 parallel E2E checks.

## Fixed

- **database**: Auto-heal SQLite FTS5 index corruption during `AutoPrune` and hard-delete lifecycle operations.
- **codemode**: Intercept and heal agent hallucinations across namespaces, method aliases, raw SQL, and nested filter objects.
- **cli**: Auto-normalize `snake_case` flags to `kebab-case` and resolve global configuration and encryption key fallbacks.
- **briefing**: Scope entry counts, orphan percentages, and summary searches strictly to the active workspace.
- **search**: Convert L2 distance to cosine similarity accurately for normalized unit vectors and fallback to FTS when empty.
- **windows**: Suppress child process terminal popups during Git spawning and harden stale backup lock cleanup against `EPERM`.

## Security

- **database**: Support full SQLite database encryption at rest via SQLCipher and `MJ_DB_ENCRYPTION_KEY`.
- **server**: Enforce `maxToolInputElements` payload array guard (25,000 default) to prevent memory exhaustion attacks.
- **healing**: Add `--no-agent-healing` toggle, enforce `allowed-io-roots` on file fallbacks, and sanitize shipped skill resources.
- **auth**: Require `exp` claims on OAuth 2.1 tokens and enforce strict query length and regex boundaries on Git mining tools.
- **sandbox**: Strip string literals prior to static security scans and isolate sandbox network calls with `SandboxNetworkError`.

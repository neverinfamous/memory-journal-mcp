# v8.0.1 Release Notes

## Highlights

- **Eliminate Vulnerabilities**: Deployed a hardened Alpine Linux base image to eradicate 50+ critical vulnerabilities and secure your container.
- **Accelerate Operations**: Restored full vector search capabilities via native C compilation of the `sqlite-vec` extension.
- **Modernized CI Pipeline**: Updated GitHub Actions to maintain rigorous supply chain security standards.

## Fixed

- **Base Image Hardening**: Reverted Docker base image to Alpine Linux to eliminate vulnerabilities.
- **Vector Search Compilation**: Restored native `sqlite-vec` compilation on Alpine to fix missing GLIBC extension load errors.

## Changed

- **Action Updates**: Bumped `docker/metadata-action` (6.1.0), `docker/scout-action` (1.21.0), and `actions/upload-artifact` (7.0.1).

## Install

```bash
docker pull writenotenow/memory-journal-mcp:v8.0.1
npm install -g @neverinfamous/memory-journal-mcp@8.0.1
```

# Memory Journal MCP v9.1.0

## Highlights

- **Autonomous Cognitive Memory Optimization**: Run full-depth NREM consolidation and REM supervisor workflows to automatically link orphans, anchor source files, and prune stale context.
- **Accelerated Hybrid Search & Tool Dispatch**: Execute FTS5 queries, vector hydration, and tool routing with significantly lower latency across large project journals.
- **Hardened Sandbox & Multi-Tenant Security**: Lock down outer worker prototypes, enforce strict RPC allowlists, and isolate multi-tenant lookups and Streamable HTTP payloads.
- **Unified Schema & CLI Precision**: Align MCP wire schemas, `ZodPipe` introspection, `--auth-scopes` CLI overrides, and OAuth author attribution across personal and team tools.
- **Expanded Verification & Coverage**: Boost unit test coverage above 85% with 2,588 unit tests and comprehensive adversarial sandbox escape and cross-subsystem checks.

## Added

- **cms**: Add autonomous full-depth NREM optimizer, `optimize-journal` REM supervisor prompt, and automatic document anchor extraction for staleness tracking.
- **prompts**: Add optional `copilotReview` toggle across all adversarial review and audit prompts to run cleanly without GitHub Copilot CLI installed.

## Changed

- **performance**: Optimize SQLite FTS5 query plans, batch vector search hydration, and pre-compile tool dispatch routing for faster execution.
- **architecture**: Modularize large source modules under the 500-line ceiling and expand unit and cross-subsystem test coverage to 85.22%.
- **dependencies**: Upgrade Alpine `expat`/`libexpat` security packages, `globals`, and pinned GitHub Actions workflow runners (`ubuntu-24.04`).

## Fixed

- **cms**: Preserve wildcard (`*`) workspace resolution in read queries, heal relationship link fallbacks, and expand staleness anchor inspection.
- **core**: Unify entry importance scoring baselines, OAuth author priority, `ZodPipe` schema unwrapping, and Code Mode schema introspection.
- **cli**: Bridge `--auth-scopes` CLI flag, ignore empty-string environment variables in `ConfigResolver`, and close `FSWatcher` handles cleanly in `exec`.
- **team**: Align team vector archive filtering, RBAC enforcement, `link_entries` parameter aliases, and batch entry metadata forwarding.
- **server**: Enforce `audit` OAuth scope checks on audit resources and normalize search filter parameters across tool handlers.

## Security

- **codemode**: Lock down outer worker function prototypes and enforce a prototype-safe RPC method allowlist to prevent cross-realm sandbox escape.
- **server**: Harden multi-tenancy workspace lookups, Streamable HTTP request body parsing, and filesystem path boundary checks across all tool groups.

npm install -g memory-journal-mcp@9.1.0

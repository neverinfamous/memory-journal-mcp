# OpenTelemetry

## Observability Patterns
- **Tracing**: Pass trace context across microservices and external boundaries.
- **Spans**: Create meaningful spans for database queries, external API calls, and LLM inferences.
- **Metrics**: Track RED metrics (Rate, Errors, Duration).
- **Exporters**: Configure standard OTLP exporters for seamless backend integration.
